# PLATZ ZWEI — порядок слов в немецком

Лендинг-разбор темы «глагол на втором месте»: правило V2, рамочная конструкция,
отделяемые приставки, вопросы, придаточные и TeKaMoLo. С анимациями, озвучкой
и конструктором предложений.

## Что внутри

- **Машина позиций (FLIP)** — меняешь начало предложения, слова физически переезжают
  по местам, глагол остаётся вторым
- **Рамочная конструкция** — скобка рисуется под предложением от спрягаемого глагола
  до второй части, ширина считается по реальной геометрии чипов
- **Полёт приставки** — «auf» отделяется от «stehen» и по дуге улетает в конец предложения
- **Конструктор** — 4 задания, тап по словам, разбор ошибки с указанием позиции
- **Озвучка** через Web Speech API: выбор голоса и скорости, сохраняется в `localStorage`
- Mobile-first, `prefers-reduced-motion`, без внешних зависимостей кроме Google Fonts

## Цветовой код

| Цвет | Роль |
|---|---|
| жёлтый | спрягаемый глагол — место 2 |
| мятный | вторая часть глагола — конец предложения |
| сиреневый | подлежащее |
| белый | остальное |

## Разработка

```bash
python3 -m http.server 4174
```
